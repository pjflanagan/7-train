
# Strava

I want to be able to load what a user has done in Strava.

- Match by activity type and replace events with what Strava has.
- If no event in our calendar, update to include one
- If our calendar event was updated more recently than the Strava post, then keep our event (users might have started recording late)

Include links to the Strava post on the event, (maybe an icon in header) so users can get more info.

There will be API limitations, only load this week and last week.
